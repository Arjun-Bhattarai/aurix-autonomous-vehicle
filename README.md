AURIX — Autonomous Urban Robotics & Intelligent eXploration:

AURIX aims to combine:

- **Autonomous Navigation:** Waypoint navigation and path planning.
- **Perception:** Sensor processing and computer vision.
- **Obstacle Avoidance:** Environment-aware driving decisions.
- **Vehicle Control:** Steering, throttle, and braking control.
- **Simulation:** Virtual vehicle testing before hardware deployment.
- **Embedded Systems:** ESP32-based physical vehicle integration.

**Technology:** Python · FastAPI · OpenCV · NumPy · ESP32 · C++

*Starting with a 1:24 BMW M4 RC drift car and evolving into a modular autonomous robotics platform.*
